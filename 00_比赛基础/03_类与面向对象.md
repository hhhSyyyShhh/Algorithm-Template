# 03 类与面向对象

## 一、从一条边开始理解【必会】

```cpp
struct Edge {
    int to;
    long long weight;
};
Edge e{2, 7};
// e.to 为 2；e.weight 为 7
```

**类/结构体是类型定义，对象是该类型的具体实例。** `Edge` 像一张“字段表格的格式”，e 才是实际的一条记录。数据成员保存状态，成员函数描述可执行的操作。

`struct` 和 `class` 都能有构造函数、成员函数、继承和虚函数。主要语言差别是：struct 的成员与继承默认 public，class 默认 private。不是“struct 只能放数据”。

## 二、一个完整的类：计数器【必会】

```cpp
class Counter {
private:
    int value_;
public:
    explicit Counter(int initial = 0) : value_(initial) {}
    void add(int delta) { value_ += delta; }
    int value() const { return value_; }
}; // 类定义结尾的分号不能漏

Counter c(3);
c.add(2); // c.value() 为 5
```

逐句拆解：

| 写法 | 含义 |
|---|---|
| `private:` | 类外不能直接访问的部分，成员函数和友元等可访问 |
| `public:` | 对外接口 |
| `Counter(...)` | 构造函数，创建对象时运行，没有返回类型 |
| `: value_(initial)` | 成员初始化列表，先初始化成员，再进入函数体 |
| `explicit` | 限制通过该构造函数进行意外的隐式转换 |
| `void add(...)` | 修改对象状态的成员函数 |
| `value() const` | 承诺不通过该函数修改普通数据成员；const 对象只能调用相应 const 接口 |
| `c.add(2)` | 用点访问对象成员 |

成员的实际初始化顺序按**类内声明顺序**，不是初始化列表中书写的先后。const 成员和引用成员通常必须在初始化列表初始化。成员函数内的 `this` 是指向当前对象的指针；`this->value_` 和无歧义时的 `value_` 指同一成员。

## 三、封装与不变量【必会】

封装是把状态与操作放在一起，并通过接口控制修改。例如并查集的父数组需要满足“每个集合有根”的结构约束，外部乱改 parent 会破坏 find/unite。

竞赛里的 DSU 常用 struct 并公开成员以简洁为主；一般项目可以把内部状态设为 private，只提供 find/unite。要理解的是**哪些修改合法、接口维持什么关系**，不必机械追求所有字段私有。

## 四、对象生命周期、析构和复制【常用】

```cpp
std::vector<int> a{1, 2};
auto b = a; // 复制容器，b 的修改不影响 a
auto& r = a; // 引用原容器，r 的修改影响 a
```

局部对象通常在离开作用域时自动析构；析构函数名为 `~类名()`，无参数、无返回值。vector/string 的析构会自动释放自己拥有的资源，这就是 RAII：资源的申请与释放跟对象生命周期绑定。

默认的对象复制按成员复制：vector 成员会复制元素；**裸指针成员只复制地址**，不会自动复制它指向的对象。如果类自行拥有 `new` 申请的内存，默认浅复制可能导致重复释放，应正确实现资源管理或使用标准容器/智能指针。优先采用“零法则”：让成员自己管理资源，通常无需手写析构与复制操作。

`std::move(x)`（<utility>）本身不是搬运操作，而是允许后续调用选择移动重载的类型转换。移动后标准库对象一般处于有效但未指定状态；可以析构或重新赋值，不能假设原内容还在。

## 五、继承与多态【了解】

```cpp
struct Shape {
    virtual double area() const = 0;
    virtual ~Shape() = default;
};
struct Square : public Shape {
    double side;
    explicit Square(double s) : side(s) {}
    double area() const override { return side * side; }
};
Square square(3);
const Shape& shape = square;
// shape.area() 调用 Square::area，得到 9
```

| 概念 | 解释 |
|---|---|
| 继承 | Square 复用/扩展 Shape 的接口，表达“是某种 Shape” |
| `virtual` | 通过基类引用/指针调用时，可按对象实际类型选择实现 |
| `= 0` | 纯虚函数；包含未实现纯虚函数的类型是抽象类，不能直接实例化 |
| `override` | 请编译器检查这确实覆盖了一个基类虚函数，写错 const 等会报错 |
| 虚析构 | 允许通过基类指针正确销毁派生对象 |
| `protected` | 类内部及派生类等可访问，普通外部代码不能直接访问 |

普通重载（同名不同参数）和虚函数覆盖（派生类重写基类虚接口）是两回事。没有 virtual 时，通过基类引用调用不会自动获得上述动态分派效果。把派生对象按值赋给基类对象会发生对象切片，应在需要多态时使用引用或指针。

组合是“有一个”，例如图拥有 vector<Edge>；继承是“是一种”。算法模板大多用组合即可。

## 六、static、运算符与智能指针【了解】

- 普通成员属于每个对象；static 数据成员在同一类的对象间共享，static 成员函数没有 this。
- C++17 可写 `inline static int count = 0;`，头文件中定义共享计数时更方便。
- `bool operator<(const Edge& other) const` 可以定义比较行为；必须满足严格弱序，不能用 <= 冒充 <。
- `std::unique_ptr<T>`（<memory>）独占所有权，不可复制，可移动；`std::make_unique<T>(...)` 创建对象，避免直接写 new/delete。
- `std::shared_ptr<T>` 共享所有权，有引用计数开销；循环拥有可能导致资源无法释放，不要只因“方便”就全部用 shared_ptr。
- 原始指针可以表达“观察某对象”，但应明确谁拥有资源。多态对象若通过基类指针析构，需要合适的虚析构设计。

## 七、回看仓库中的写法

`DSU(int n):p(n),sz(n,1){...}` 是构造函数初始化两个 vector；`int find(int x)` 是成员函数；`DSU d(5); d.unite(0,1);` 是创建对象再调用接口。

**自测**：给 Counter 加 reset；说明 class 与 struct 的默认访问区别；解释为什么通过基类指针 delete 派生对象时需要虚析构。
