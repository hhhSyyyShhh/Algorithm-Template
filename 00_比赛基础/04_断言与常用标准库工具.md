# 04 assert、检查机制与常用标准库工具

## 一、先分清“宏、关键字、函数”【必会】

| 写法 | 属于什么 | 头文件 | 什么时候发生 |
|---|---|---|---|
| `assert(expr)` | 函数式宏，不是普通函数 | `<cassert>` | 启用时在运行期判断 |
| `static_assert(expr,"说明")` | 语言关键字/声明 | 不需要 | 编译期检查常量表达式 |
| `if (...)` | 控制语句 | 不需要 | 运行期执行判断与分支 |
| `v.at(i)` | 容器成员函数 | `<vector>` 等 | 访问时检查越界，失败抛异常 |
| `throw` / `try` / `catch` | 异常处理语言机制 | 关键字无需头文件；异常类另需头文件 | 运行期异常传播和处理 |
| `abort()` | 标准库函数 | `<cstdlib>` | 异常终止程序 |
| `exit(code)` | 标准库函数 | `<cstdlib>` | 终止程序，有不同于 return 的清理规则 |
| `sizeof(T)` | 语言运算符 | 不需要 | 得到对象表示占用字节数，结果类型 size_t |

并非所有写成 `name(...)` 的东西都是函数。编译器提供的 `__builtin_popcount` 则是另一类扩展，不能和 ISO C++ 标准库混为一谈。

## 二、assert 到底做什么【必会】

```cpp
#include <cassert>
int n = 5;
assert(n >= 0); // 真：继续；假：报告断言失败并异常终止
```

用途是检查“程序员认为此处必须满足的条件”，例如线段树 n>0、树状数组更新下标不能为 0、测试结果应与手算一致。

- 条件为真：继续执行；assert 本身不给你返回一个布尔结果。
- 条件为假：通常向标准错误输出表达式/位置等诊断并终止；具体格式由实现决定。
- **断言失败不是抛出 C++ 异常**，不能指望用 catch 捕获它。
- 它不会证明算法对所有输入都正确；示例断言只检查这些具体用例。

### NDEBUG：断言可能完全不执行

在包含 `<cassert>` 前定义 NDEBUG，或编译时传 `-DNDEBUG`，可以关闭断言；条件表达式也不再求值。是否启用由这个宏决定，不由你主观称“Debug/Release”决定。

```cpp
int count = 0;
assert(++count == 1); // 错误习惯！关闭 assert 后 ++count 根本不执行
```

正确做法是先完成操作，再检查结果：

```cpp
++count;
assert(count == 1);
```

同理，不要在 assert 中放 `cin >> n`、push_back、数据库写入等必要操作。这个仓库最初的算法示例把部分测试调用放在 assert 中：**必须启用断言运行验证**；关闭后这些用例会被跳过，打印 OK 也不等于实际执行过测试。

### 说明文字与逗号

C++17 的 assert 宏接收一个宏参数。表达式中模板逗号、初始化列表逗号等可能被预处理器当成分隔符，给整个表达式再加一层括号：

```cpp
assert((std::pair<int,int>{1,2} == std::make_pair(1,2)));
assert((n > 0) && "n must be positive"); // 字符串帮助阅读失败表达式，不是第二个参数
```

`assert(condition,"message")` 不是通用 C++17 写法。上面的字符串本身会转换为真，不改变前面的条件含义。

### assert 不能代替正常输入检查

如果外部输入可能不合法，应使用明确的 if/返回值/异常处理，避免在关闭断言后继续执行危险操作：

```cpp
if (index < 0 || index >= static_cast<int>(a.size())) {
    std::cerr << "index out of range\n";
    return 1; // 这里假设位于 main 中
}
```

## 三、static_assert【常用】

```cpp
static_assert(sizeof(long long) >= 8, "need at least 8 bytes");
```

条件必须是可在编译期求值的常量表达式；失败时编译不通过，不会等到运行才报错。运行时读入的 n 不能直接拿来 static_assert。

它不受 NDEBUG 控制。C++17 允许省略消息：`static_assert(sizeof(int)>=2);`。sizeof 的单位是 C++ 的 byte；在本仓库常见平台上一个 byte 为 8 位，不要把它理解成标准无条件要求所有机器都如此。

## 四、at 与异常【常用】

```cpp
try {
    std::cout << a.at(100) << '\n';
} catch (const std::out_of_range& e) { // <stdexcept>
    std::cerr << e.what() << '\n';
}
```

`a[i]` 不要求实现检查普通越界；`a.at(i)` 检查并在越界时抛 out_of_range。map.at(key) 在缺键时也抛同类异常，map[key] 则会插入。

`throw std::invalid_argument("bad n")` 可报告参数错误；异常不是普通分支的廉价替代品。竞赛题通常保证输入符合题面，应按条件写程序，在调试阶段加强检查。

## 五、return、exit、abort 的区别【了解】

| 写法 | 作用 | 局部对象清理 |
|---|---|---|
| 普通函数 `return` | 返回调用者 | 离开作用域，正常析构 |
| main 中 `return 0` | 正常结束程序 | main 的局部对象正常析构 |
| `std::exit(code)` | 终止整个程序，执行其正常终止清理机制 | 不展开当前调用栈，自动局部对象不按栈展开析构 |
| `std::abort()` | 异常终止 | 不保证执行正常清理，不应依赖析构 |

写普通算法程序优先从 main 返回，不必主动调用 exit/abort。断言失败使用异常终止机制，不能把它当成资源清理方案。

## 六、常用数值与字符串工具【常用】

| 接口 | 头文件 | 解释与注意 |
|---|---|---|
| `min(a,b)` / `max(a,b)` | `<algorithm>` | 返回较小/较大值，通常需一致类型；不要保留临时参数返回的引用 |
| `min({a,b,c})` | `<algorithm>` | 初始化列表版本，求多值最小；不能给空列表 |
| `swap(a,b)` | `<utility>` | 交换值，复杂度取决于类型；交换两个 vector 通常 O(1) |
| `clamp(x,lo,hi)` | `<algorithm>` | C++17，将 x 限制在区间，要求 lo<=hi；留意返回引用的生命周期 |
| `abs(x)` | `<cstdlib>` / `<cmath>` | 整数/浮点绝对值；最小负整数的正值可能无法表示 |
| `sqrt(x)` / `pow(x,y)` | `<cmath>` | 浮点平方根/幂；开方要求非负实数；不用于精确大整数幂或整数边界判断 |
| `floor` / `ceil` / `round` | `<cmath>` | 向下/向上/四舍五入（半整数远离零），如 floor(-1.2)=-2、ceil(-1.2)=-1 |
| `numeric_limits<T>::max()` / `lowest()` | `<limits>` | 最大/最小有限值；浮点 min() 是最小正正规值，不是最负值 |
| `stoi` / `stoll` | `<string>` | 字符串转 int/long long；非法或越界会抛异常；可能只解析前缀，用 pos 检查是否整串解析 |
| `to_string(x)` | `<string>` | 数值转字符串；浮点文本精度不等于任意高精度格式化 |
| `isdigit` / `isalpha` / `isspace` | `<cctype>` | 返回是否数字/字母/空白（非零为真）；依赖 locale，逐字节处理 |
| `tolower` / `toupper` | `<cctype>` | 大小写转换，返回 int；不能当作通用 Unicode 转换 |
| `memset(ptr,byte,count)` | `<cstring>` | 按字节写，不是按整数赋值；只用于适合的原始存储，不用于 vector/string 对象 |
| `memcpy(dst,src,count)` | `<cstring>` | 字节复制，区域不可重叠；不是含资源类的安全复制方式 |
| `fill(first,last,value)` | `<algorithm>` | 按元素赋值，给 int 数组填 1 应用它而不是 memset(...,1,...) |

### 两个尤其常见的坑

1. `memset(int_array,1,sizeof int_array)` 每个字节都设为 1，整数通常变成 0x01010101，不是数值 1。需要填 1 用 fill。
2. cctype 接受 EOF 或可表示为 unsigned char 的值；普通 char 可能有符号，写 `std::isdigit(static_cast<unsigned char>(ch))` 更安全，返回值用 `!=0` 判断。

stoi 示例：`size_t pos=0; int x=stoi("12x",&pos);` 会得到 x=12、pos=2，并不自动认为末尾 x 是错误。若不允许后缀，检查 pos==s.size()，并处理异常。

## 七、编译器扩展【了解】

GCC/Clang 常有 `__builtin_popcount(unsigned)`、`__builtin_popcountll(unsigned long long)`。它们统计二进制中 1 的数量，但不是 C++17 标准接口。标准 C++20 才有 `<bit>` 中的 `std::popcount`。

`__builtin_clz/ctz` 等扩展在输入 0 时可能没有定义，使用前查当前编译器约定。本仓库优先用标准 C++17 写法，不把这些扩展当作所有编译器内置必有。
