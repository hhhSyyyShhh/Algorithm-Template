# 01 C++ 基础语法

## 一、程序从哪里开始【必会】

```cpp
#include <iostream>   // 提供 cin、cout
#include <vector>     // 提供 vector

int main() {
    int n = 3;
    std::vector<int> a(n, 0);
    std::cout << a.size() << '\n';
    return 0;
}
```

`#include` 是预处理指令；`std` 是标准库使用的命名空间；`::` 表示作用域限定。`std::vector<int>` 表示元素类型是 int 的 vector。`main` 是程序入口，返回 0 表示正常结束。

竞赛中常见 `using namespace std;`，这样可以直接写 `vector`、`cout`；大型项目中应留意名称冲突。`using ll = long long;` 是类型别名，不会创建变量。`<bits/stdc++.h>` 不是标准头文件，Mac 默认 Clang 环境不保证支持。

## 二、变量、类型与初始化【必会】

| 写法 | 含义 | 注意 |
|---|---|---|
| `int x = 0;` | 普通整数 | 竞赛平台通常为 32 位，标准只保证至少 16 位 |
| `long long sum = 0;` | 较大整数 | 至少 64 位；仍会溢出 |
| `double p = 0.5;` | 浮点数 | 有舍入误差，不适合精确整数计数 |
| `bool ok = true;` | 真/假 | 条件判断使用 |
| `char ch = 'a';` | 单个字符 | 单引号；与字符串 `"a"` 不同 |
| `std::string s = "abc";` | 字符串 | 需要 `<string>` |
| `const int n = 10;` | 初始化后不能通过该名字修改 | const 不总意味着编译期常量 |
| `constexpr int N = 100;` | 编译期常量表达式变量 | 用于固定配置等 |
| `auto x = 3;` | 推导为 int | `auto` 不是动态类型 |
| `auto& x = a[0];` | 元素的引用 | 修改 x 会修改原元素 |

局部基本类型变量 `int x;` 没有自动清零，读取未初始化的值有风险；写 `int x{};` 或 `int x=0;`。`vector<int> a(n)` 的 n 个整数会初始化为 0。局部大数组和深递归可能耗尽栈。

## 三、运算符与类型转换【必会】

| 运算 | 示例 | 结果/含义 |
|---|---|---|
| 整数除法 | `7 / 2` | 3，向零截断 |
| 浮点除法 | `7 / 2.0` | 3.5 |
| 余数 | `7 % 2` | 1；除数不得为 0 |
| 比较 | `a == b`、`a != b` | 相等/不相等 |
| 赋值 | `a = b` | 把 b 写入 a；与 `==` 区分 |
| 逻辑 | `&&`、`\|\|`、`!` | 与、或、非，前两者短路求值 |
| 位运算 | `&`、`\|`、`^`、`~` | 按位与、或、异或、取反 |
| 位移 | `1ULL << k` | 对无符号数左移；0<=k<类型位数 |
| 条件表达式 | `ok ? x : y` | 条件真取 x，否则取 y |
| 自增 | `++i`、`i++` | 都增加 1；作为表达式时返回值不同 |

`a & b` 与 `a && b` 的含义和优先级都不同。位判断写 `(mask & (1ULL << k)) != 0`，不要靠记忆猜复杂表达式的优先级。

```cpp
int a = 100000, b = 100000;
long long wrong = a * b;      // 先按 int 乘，可能已经溢出
long long right = 1LL * a * b; // 乘法开始前提升类型
int index = static_cast<int>(values.size()); // 仅在长度确实能放入 int 时使用
```

有符号整数溢出是未定义行为，不能依赖“自然绕回”。`LLONG_MAX` 可来自 `<climits>`；更通用的类型上界是 `<limits>` 的 `numeric_limits<T>::max()`。

C++ 的负数余数可能为负。模数 `m>0` 且中间结果不溢出时，可用 `(x % m + m) % m` 规范到 `[0,m)`。

## 四、条件与循环【必会】

```cpp
if (x > 0) { /* 正数 */ }
else if (x == 0) { /* 零 */ }
else { /* 负数 */ }

for (int i = 0; i < n; ++i) { /* i: 0 到 n-1 */ }
while (!q.empty()) { /* 处理队列，并保证循环能向结束推进 */ }
for (int x : a) { /* 复制每个元素，修改 x 不影响 a */ }
for (int& x : a) { x += 1; } // 引用，修改原数组
for (const auto& x : a) { /* 只读，避免不必要复制 */ }
```

`break` 退出最近一层循环；`continue` 跳过本轮剩余部分；`return` 结束当前函数。变量的作用域通常到所在花括号结束，内层同名变量会遮蔽外层。

## 五、数组与多维数组【必会】

```cpp
int a[3] = {1, 2, 3}; // 合法下标 0、1、2
std::array<int, 3> fixed{1, 2, 3}; // <array>，固定长度、有 size()
std::vector<int> dynamic(3, 0);    // 动态长度
std::vector<std::vector<int>> grid(2, std::vector<int>(3, 0));
```

`a[3]` 越界，不是第 3 个元素；`grid[i][j]` 是第 i 行第 j 列。二维 vector 每行是独立容器。`int a[n]` 中若 n 在运行期确定，是部分编译器扩展，不是标准 C++17；用 vector。

不要写 `for (size_t i=a.size()-1; i>=0; --i)`：size_t 无符号，不会降到 -1。竞赛规模可转 int 后写 `for (int i=(int)a.size()-1; i>=0; --i)`。

## 六、输入输出【必会】

```cpp
std::ios::sync_with_stdio(false);
std::cin.tie(nullptr);
int n;
if (!(std::cin >> n)) return 0; // 读取失败则退出 main
std::cout << n << '\n';
```

`cin >> s` 读取到空白为止；`getline(cin,s)` 读取整行。前面刚用过 `>>` 时，残留换行可能导致 getline 读到空行：按题意用 `cin.ignore(numeric_limits<streamsize>::max(), '\n')` 消耗当前行剩余部分。若用 `getline(cin >> ws,s)`，会跳过所有前导空白与空行，可能改变有意义的数据。

`'\n'` 是换行字符；`endl` 除了换行还刷新输出，频繁使用可能降低性能。关闭同步后避免混用 cin/cout 与 scanf/printf。

输出小数需要 `<iomanip>`：`cout << fixed << setprecision(2) << x;`，表示保留两位小数。交互题需要按协议及时刷新，不能照搬普通题输出策略。

## 七、头文件与声明【常用】

函数先声明再调用，或把定义放到调用之前；`void` 表示无返回值。自己拆文件时，头文件可放声明与类型定义，使用 include guard 或 `#pragma once` 防止重复包含（后者广泛支持但不是标准指令）。不要把多个有 main 的模板一起链接。
