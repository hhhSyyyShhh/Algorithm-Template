# ACM / ICPC C++17 算法模板与学习笔记

这是一套对应本次目录讨论的**基础与常用进阶模板**，不是整个竞赛算法的全集。每份 cpp 都可独立编译运行，包含中文说明、实现与带断言的使用示例。无需一次学完。

## C++ 前置知识

从 [前置知识学习入口](00_比赛基础/README.md) 开始，包含基础语法、引用指针与 Lambda、类与面向对象、STL 接口、assert 与标准库工具、读模板与排错，以及可运行示例。

## 如何使用

1. 先读用途与适用条件，判断题目是否满足条件。
2. 手算 main 的例子，画出数组、队列、栈或递归过程。
3. 编译运行，修改输入，检查边界。断言通过会打印 OK。
4. 遮住代码重新实现，再完成一题同类题。
5. 实际提交时只复制需要的函数/结构体，把示例 main 换成题目要求的输入输出。**这些示例不是通用在线评测答案。**

Mac 上无需 bits/stdc++.h，模板全部使用标准头文件。单文件示例：

```bash
cd ~/Desktop/Algorithm-Template
mkdir -p build
clang++ -std=c++17 -Wall -Wextra -pedantic "01_基础算法/前缀和与差分/一维前缀和.cpp" -o build/demo
./build/demo
```

## 统一约定与边界

- 默认 0 下标；树状数组单独采用 1 下标。区间通常闭区间，字符串哈希和标准库采用半开区间，详见各文件。
- long long 也会溢出，必须按题目上界估算；模板只在声明的数值范围内保证正确。
- 递归深度可能达到节点数，超长链应改为显式栈或迭代；本地能跑不代表评测机栈足够。
- 树模板假设连通无环；普通图需要 visited。无向图加双向边。
- dp 必须先定义“状态表示什么”，再决定初值和循环顺序；贪心必须证明局部选择不会损害全局解。
- 为便于独立运行，各文件重复了头文件；不用把所有 cpp 链接成一个程序，它们各有 main。

## 建议学习顺序

| 轮次 | 内容 | 达标方式 |
|---|---|---|
| 第一轮 | C++/STL、复杂度、排序、前缀和/差分、二分、双指针、GCD、快速幂 | 能说明适用条件，独立写出实现，并处理空输入/端点 |
| 第二轮 | DFS/BFS、回溯、二叉树、贪心、基础背包与 LIS、并查集 | 能画出状态变化，解释为什么正确 |
| 第三轮 | 拓扑、最短路、最小生成树、筛法、组合数、KMP/Trie | 能区分相似模型并选择算法 |
| 第四轮 | 线段树、LCA、树形/区间/状态压缩 DP、哈希 | 通过补题逐项掌握，不必硬背整份代码 |

把完整比赛题解放在另一个刷题目录；这里保留精简、可复用且有适用条件的模板。
